# Security audit reports

One file per audit run, named `security-audit-YYYY-MM-DD.md`, written by
`.claude/skills/maintenance/security.md`.

**A report is a record of one run, not a to-do list.** The open work lives in
`../security-backlog.md`. A report is never rewritten after the fact except to add a single line
marking a finding fixed — which is what keeps these readable as history.
