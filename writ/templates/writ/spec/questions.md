# Open questions

> **Role:** every question nobody has answered yet, wherever it arose — the specification, the
> milestone plan, a foundation spec, a slice. **One family, one file:** the `Scope` column says
> where it belongs, so there is no second list to read. **A register:** one table.
>
> **Closing one is a status, not a strikethrough.** Set `Status` to `closed`, name what closed it
> under `Closed by` — an ADR, an amendment, a change request — and put the reasoning there, never
> in this row. A row is a line.
> **`Recommended` is not optional.** The option you would pick and, in a clause, why — so the
> decider starts from a proposal rather than a blank. A question nobody can recommend an answer to
> yet says what would let them.
> **Owner:** whoever the `Decider` column names.
